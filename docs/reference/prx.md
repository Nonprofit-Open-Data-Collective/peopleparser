# Known Prefix (Salutation / Title) Strings

A character vector of upper-cased salutations, titles, degrees, ranks,
and credentials that
[`parse_name()`](https://nonprofit-open-data-collective.github.io/peopleparser/reference/parse_name.md)
removes wherever they occur in a name and reports in the `salutation`
column. Some further titles are removed only by position; see
[`vignette("name-cleaning")`](https://nonprofit-open-data-collective.github.io/peopleparser/articles/name-cleaning.md).

## Usage

``` r
prx
```

## Format

A character vector.
